# GitHub 展示设置草稿

状态：仅准备文案，尚未修改远程设置。项目主体仍是“叶瞬光桌面宠物”，不更换仓库名或下载地址。

## 仓库简介

Windows 离线桌面陪伴：可换角色皮肤、迷你番茄钟、学习记录。无需登录，非官方同人项目。

## Topics


这些标签描述现有功能，不加入 `ai-chat`、`cross-platform` 等不符合当前版本的标签。若远程已有其他准确标签，先核对再合并，不直接覆盖。

## 分享封面

使用 [social-preview.png](../media/social-preview.png)，尺寸 1280 × 640，生成脚本会检查小于 1 MB。

设置位置：仓库 Settings → General → Social preview → Edit → Upload an image。图片上传后，某些外部平台仍可能保留旧预览缓存。

## 应用顺序

1. 先提交 README、媒体和反馈表单，确认远程链接有效。
2. 仓库主页 About 的编辑入口填写简介与 Topics。
3. 单独上传分享封面。
4. Homepage 暂时留空；没有独立网站时不编造网址，也不为了填这个字段先增加维护负担。
5. 在退出登录的浏览器中检查公开主页和下载链接，不以自己的已登录页面代替新用户视角。

这些操作需要仓库写权限。不要为此把访问令牌写进文档、脚本或公开 Issue。

官方说明：[仓库 Topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics)、[Social preview](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)。
