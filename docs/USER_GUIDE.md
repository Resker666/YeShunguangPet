# 叶瞬光桌面宠物：完整使用与开发说明

[返回项目首页](../README.md) · [下载最新版本](https://github.com/Resker666/YeShunguangPet/releases/latest)

一个不依赖 Codex 的 Windows WPF 桌面助手。程序从本地皮肤包读取动画，随附叶瞬光，可以离线运行，不需要 API key。

## 下载与运行

前往 [Releases](https://github.com/Resker666/YeShunguangPet/releases/latest)，下载 Windows x64 便携版 ZIP，解压到一个固定目录后运行 `YeShunguangPet.exe`。

- 支持 Windows 10/11 x64。
- 不需要管理员权限。
- 不需要安装 .NET、Codex 或其他运行库。
- 建议先解压再运行，不要直接在压缩包预览窗口中启动。
- 从 v1.2.0 起，EXE 和旁边的 `Pets` 文件夹必须一起保留；升级时解压完整 ZIP，不能只替换 EXE。

当前程序没有商业代码签名。Windows 可能显示“Windows 已保护你的电脑”或“未知发布者”。请先确认文件来自本仓库的 Release，并核对同一 Release 中的 SHA256 文件；只有在来源和哈希都正确时再决定是否运行。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动当前角色 |
| 单击角色 | 打招呼（等待系统双击判定时间后播放） |
| 双击角色 | 跳跃互动；没有跳跃动作的皮肤回退为打招呼或待机 |
| 右键 | 打开动作和设置菜单 |
| 默认 `Ctrl + Alt + Y` | 召回全部角色到主屏幕，并关闭它们的点击穿透；可在快捷键设置中修改 |
| 托盘图标双击 | 切换全部角色的显示状态 |
| 托盘或右键菜单“角色管理” | 添加、隐藏、召回、配置和关闭角色 |
| 角色右键菜单“设置” | 调整当前角色；“专注与休息”对所有角色生效 |
| 右键或托盘菜单“专注计时” | 打开番茄钟 |
| 托盘菜单“勿扰模式” | 暂停自动动作和通知 |
| 角色右键菜单“查看角色介绍” | 打开只读介绍，不改变角色或计时 |
| 角色右键菜单“关闭此角色” | 确认后关闭当前实例，不删除皮肤，不停止专注计时 |
| 托盘菜单“退出程序” | 关闭所有角色和计时，完全退出程序 |

v2 设置保存在 `%APPDATA%\YeShunguangPet\desktop-v2.json`，上一版保存内容位于同名 `.bak` 文件。首次运行 v2 时读取旧 `settings.json`，迁移为一个角色，但不修改旧文件。位置、大小、显示状态、窗口和行为选项会在下次运行时恢复。本地日志位于 `%APPDATA%\YeShunguangPet\logs`。

开启“点击穿透”后，角色窗口不会接收鼠标操作。可在托盘“角色管理”中选中角色并打开设置关闭穿透，或按全局召回快捷键。

### 桌面右键菜单（v2.4）

- 常用入口保留在第一层：“专注计时”“设置”“查看角色介绍”“角色管理”；七个动画命令收进“动作”。
- 放大、缩小、置顶、点击穿透、随机待机、桌面走动和开机启动收进“显示与行为”。没有对应动作的皮肤仍禁用不适用项。
- “隐藏此角色”保留实例，“关闭此角色”需确认后移除实例，“退出程序”结束整个应用。三者分组展示；关闭角色不会删除皮肤文件。
- 介绍窗口只显示角色图像、名称、描述和基本信息，关闭介绍不会关闭角色。菜单跟随深浅色主题，保留快捷键提示、键盘选择和子菜单行为。

### 可配置快捷键（v2.10）

入口为“角色管理 → 设置 → 应用 → 快捷键”，或角色“设置 → 常规”中召回快捷键旁的键盘按钮。所有角色共用一套全局快捷键。

| 操作 | 默认 | 行为 |
| --- | --- | --- |
| 召回全部角色 | Ctrl+Alt+Y | 召回全部到主屏幕并关闭点击穿透；没有角色时不创建新角色 |
| 打开专注计时 | 未启用 | 打开或还原既有面板，保持当前阶段与剩余时间 |
| 开始 / 暂停计时 | 未启用 | 运行时暂停，暂停时继续，准备或完成时按原流程开始下一段；面板关闭时仍可计时，不弹出新窗口 |
| 切换迷你模式 | 未启用 | 已打开时切换完整/迷你布局；面板关闭时直接打开迷你钟，仍使用同一计时会话 |

1. 打开对应操作右侧的开关，在下拉框中选择修饰键组合与按键，再点“保存”。关闭开关代表不注册该操作。未启用行里预选的组合不是已经生效的快捷键。
2. 支持 Ctrl+Alt、Ctrl+Shift、Alt+Shift、Ctrl+Alt+Shift，配合 A-Z、0-9、Space 或 F1-F11。本版不支持裸键、单个修饰键或 Win 组合，不拦截普通文字输入。
3. 重复组合、系统占用或保存失败时会提示并保留草稿；原配置与已注册快捷键不变。修改组合或关闭占用该键的软件后可重新保存。
4. “恢复默认”只修改草稿，保存后才恢复为仅启用 Ctrl+Alt+Y。取消或关闭窗口不会修改配置。
5. 启动时被其他软件占用的快捷键会显示注册失败，其余操作仍可使用。菜单命令始终保留，可通过托盘恢复操作；释放冲突后在快捷键窗口再次保存以重试。

快捷键窗口打开时不执行快捷键；角色设置或其他模态窗口打开期间，不执行计时类快捷键。计时面板中的无效分钟草稿同样会阻止开始，不会绕过原来的校验。长按组合键不重复触发操作。

配置使用 `desktop-v2.json` 的可选 `Shortcuts` 字段，每项为包含 `Modifiers`、`Key` 的对象，`null` 表示禁用。字段缺失时沿用默认召回组合。退出时注销已注册组合，不监听或记录其他键盘输入，不需要管理员权限。旧版本不支持自定义快捷键，降级保存配置可能清除这些字段。

## 截图与贴图（v2.11）

截图为内置功能，不需要安装 Snipaste，也不需要联网或 API key。

1. 从角色右键、控制中心或托盘打开“截图”，选择“区域截图”“当前屏幕”或“全部屏幕”。当前屏幕指调用时鼠标所在显示器；全部屏幕包含整个虚拟桌面及屏幕之间的空隙。两种整屏入口直接预选对应范围，仍可原地标注后完成。
2. 本程序当前可见的角色、计时面板、控制中心、诊断窗口和贴图会临时隐藏。区域模式拖动框选，松手后选区保留在原桌面上，不跳到独立图片编辑窗口。原本隐藏或最小化的窗口不会被强制显示，隐藏偏好不会改变。
3. 选区左上显示实际像素尺寸；八个手柄和边缘可调整范围。“调整选区”工具下拖动选区内部可移动整个框，方向键微移 1 像素，Shift+方向键移动 10 像素。扩大选区会恢复该处的原始桌面像素，标注保持原图位置，不随框拉伸。
4. 工具栏默认靠近选区下方，空间不足时移到上方或选区内；不会进入最终截图。支持矩形、椭圆、箭头、画笔、文字和实色遮挡。颜色、线宽、字号只在对应工具选中时展开；再次点击当前标注工具可回到调整选区。
5. 文字工具选中后点击图片原地输入；Enter 或移开焦点提交文字，Shift+Enter 换行，Esc 放弃正在输入的文字。撤销/重做覆盖标注和选区调整，支持 Ctrl+Z、Ctrl+Y。
6. 点击绿色完成按钮、Enter 或非文字输入框中的 Ctrl+C，复制当前选区并退出全部浮层。保存按钮或 Ctrl+S 选择 PNG，成功后退出；取消保存则留在截图中。贴图按钮生成桌面贴图并退出。剪贴板占用、保存失败或贴图容量不足会保留当前截图供重试。
7. 没有输入或拖动时，Esc 或右键取消整次截图；拖动中 Esc 先恢复上一次选区，输入文字时 Esc 先取消文字。截图会话进行中重复触发截图不会启动第二份会话。工具栏关闭、显示器布局变化或锁屏也会取消浮层。

三个截图操作均可在“设置 → 应用 → 快捷键”中独立启用；预选组合分别为 Ctrl+Alt+S、Ctrl+Alt+D、Ctrl+Alt+A，默认均不注册，不影响已有快捷键。

### 桌面贴图

- 拖动图片或空白边框可移动；滚轮缩放，双击恢复合适大小。显示范围受当前屏幕工作区约束；缩放不会改变复制/保存时的原始像素。
- 鼠标移入贴图后显示图钉、更多操作和关闭按钮。图钉控制置顶；更多菜单支持复制、保存、缩放、隐藏和关闭。
- 贴图获得键盘焦点后，可用 Ctrl+C 复制、Ctrl+S 保存，+/- 缩放、0 恢复大小、Esc 或 Delete 关闭。
- 托盘“贴图”可从剪贴板图片创建贴图，或统一显示、隐藏、关闭已有贴图。只有主动选择粘贴时才读取剪贴板，不读取剪贴板文本或文件列表。
- 隐藏保留图片，关闭释放这张贴图；退出程序关闭全部贴图。需要长期保留时请明确保存 PNG。本版没有自动截图历史或贴图恢复文件。

### 隐私与限制

- 截图仅由手动命令触发，计时结束不会自动读取屏幕。不会上传或把截图加入诊断包。
- 遮挡是完全不透明的黑色覆盖，不是模糊或可还原的导出图层；导出仅包含合成位图和选定区域。浮层中仍可撤销并调整选区，因此结束前会保留原始快照，分享前请检查覆盖范围。
- 单次快照的显示器包围矩形最多 3200 万像素，屏幕之间的空隙也计入；超过限制会提示，不偷偷缩小图片。单边最多 32768 像素。
- 贴图最多 8 张，合计最多 4800 万像素；标注最多 300 个，撤销历史最多 100 步。单笔最多 10000 个采样点，文档内画笔点数最多 100000。
- 锁屏、安全桌面、远程会话切换和受保护内容可能无法截取；不尝试绕过系统限制。显示器布局变化会取消正在进行的框选。混合 DPI、HDR 色彩及特殊显卡环境仍需在实际设备上验收。
- 本版支持区域/整屏截图与轻量标注，不包含 OCR、滚动长截图、自动识别窗口边缘或完整 Snipaste/微信功能。

## 多角色桌面

1. 从托盘或角色右键打开“角色管理”（控制中心），点击“添加角色”，在弹窗中选择皮肤并添加。最多保留 3 个实例（包含隐藏角色），同一皮肤也可添加多次。
2. 每个角色可独立拖动、缩放、设置、漫游和贴边收纳，互不改变其他角色的参数。
3. “隐藏”暂时停用该角色的绘制与行为定时器，保留实例和位置；“关闭角色”从桌面配置中移除实例，皮肤文件保留，可再次添加。
4. 专注计时、提醒、勿扰、开机启动、系统托盘和全局快捷键只有一份。关闭某个角色或全部角色不会结束计时，仍可通过托盘重新添加角色。
5. “专注计时”复用同一个窗口；从角色打开时显示该角色头像。完成通知只发送一次，各角色分别遵守自己的拖动、菜单和隐藏状态决定是否播放动作。

角色列表中的序号是当前排列顺序，不是皮肤 ID。保存或更新皮肤只在当前实例的设置保存后加载，其他已打开实例保留各自加载的快照，重新保存设置或重启后读取新文件。不能删除仍被任一实例使用的皮肤。

设置窗口打开期间，先关闭设置窗口再增删角色或退出程序，避免丢弃未保存的编辑器草稿。角色管理窗口可关闭或最小化，不影响桌面角色。

### 控制中心与外观（v2.1）

自 v2.10 起，各工具窗口共用系统字体、22 号页面标题、15 号分组标题和 20 号确认弹窗标题，表单与图标按钮保留清晰的键盘焦点边界。保留原生标题栏；深浅主题、强调色、高对比度和减少动态效果仍沿用原有设置。日志等需要等宽字体的内容不做替换。

- **桌面角色**：选中卡片后，在下方调整大小、置顶、贴边收纳和点击穿透。眼睛按钮切换显示，齿轮打开详细设置，“更多”菜单可以召回或关闭该角色。
- **即时保存**：控制中心的快捷修改直接生效，连续缩放约 220 毫秒后合并保存；关闭窗口也会保存最后的调整。详细设置仍采用“保存 / 取消”，两者不要混淆。
- **设置 → 应用**：选择跟随系统、浅色或深色主题，以及绯红、青绿、蔚蓝或石墨强调色。外观会同步到已打开的工具窗口，并在下次启动时恢复。
- **设置 → 当前角色**：可切换当前操作的实例，继续调整窗口选项，或进入皮肤与详细设置。已有的行为、漫游、学习和备份功能仍在原来的设置入口中。
- **减少动态效果**：关闭装饰性过渡、平滑滚动和自动头像预览；不会停掉桌面宠物动画或专注计时。皮肤页的重播按钮、编辑器的播放按钮仍可手动预览动作。
- **托盘右键菜单（v2.1.2）**：常用入口与桌面操作分组显示，跟随深浅色主题，快捷键在右侧对齐。勿扰的勾选表示手动勿扰开关；没有角色时禁用显示、隐藏和召回全部。菜单仍支持键盘选择、Esc 关闭及点击外部关闭，阴影遵循系统视觉设置。
- 新外观字段保存在原有 `desktop-v2.json` 中。v2.0 配置不需要手工迁移；程序不会为 UI 升级改动或重新生成任何 PNG。
- 升级试用前先从托盘退出旧版，再运行新版。直接再次双击 EXE 只会唤醒已运行的旧进程，不会热替换它。

开发者可执行 `dotnet run --project tests/PetTests.csproj --configuration Release -- . artifacts/ui-smoke --ui-smoke` 运行隔离的原生 UI 检查。测试使用临时配置和屏幕外窗口，不修改个人设置或注册开机启动。

### 从 v1 升级

- 先从托盘退出旧版本，再解压并运行完整 v2 ZIP。旧版和新版共用单实例标识，同时启动只会唤醒已运行的程序。
- 首次迁移保留旧角色、位置、大小、行为和陪伴偏好；导入皮肤及备份目录不移动、不删除，PNG 与皮肤 `schemaVersion: 1` 不变。
- 已有有效 `desktop-v2.json` 时不会再次迁移旧配置。配置损坏或版本不支持会报错退出，不自动覆盖为默认值。
- 需要恢复配置时，退出程序，保留损坏文件，再将 `desktop-v2.json.bak` 的内容恢复到 `desktop-v2.json`。
- 回退运行 v1 时仍读取旧 `settings.json`，不会读取或改写 v2 的多角色配置；v2 中新改的参数不会同步回 v1。
- 开机启动记录包含 EXE 路径。升级到新目录后，应在新版本的角色设置中重新确认开机启动，程序不会擅自迁移旧启动路径。

## 主要功能

- 透明无边框、可拖动、可缩放的桌面动画
- 鼠标靠近时看向鼠标方向
- 手动播放待机、打招呼、跳跃、工作、等待和检查等动作
- 系统托盘显示/隐藏与完整退出
- 可选总在最前、点击穿透和开机启动
- 可调随机待机动作和触发间隔
- 可选桌面横向走动、走动间隔和速度
- `Ctrl + Alt + Y` 全局召回快捷键
- 常规、行为和关于设置页面
- 皮肤缩略图列表、动作预览、ZIP 导入导出、同 ID 更新与删除保护，保存后即时切换
- 可视化动作配置编辑器，逐帧调速、网格定位、注视方向配置，不改变原始 PNG
- 皮肤历史版本与已删除备份列表、恢复为副本、确认后永久清理
- 外部 `pet.json` 动作参数与 PNG 精灵图，无需重新编译即可增加角色
- 本地故障日志与日志目录入口
- 单应用实例运行，应用内支持最多 3 个角色，共享托盘与计时
- 多显示器位置保护和 Per-Monitor V2 DPI 支持
- 区分点击与拖动，单击打招呼、双击跳跃
- 自动走动时靠近停步、离开继续，并在工作区边缘转向
- 专注/休息番茄钟，支持暂停、继续、结束和跳过休息
- 桌面角色与计时面板头像同步专注与休息状态：专注时工作，暂停或休息时待机，完成时短暂挥手
- 可选定时休息提醒、手动勿扰和跨午夜勿扰时段
- 四边贴边收纳：拖到边缘松手后滑入，悬停把手展开，鼠标离开后自动收回

## 贴边自动隐藏

在“设置 → 常规”开启“贴边自动隐藏（四边）”，默认关闭。

1. 把角色拖到当前显示器可用区域的左、右、上或下边缘附近，松开鼠标后收纳。判定距离约 24 个逻辑像素；角落优先选择最近的一边，距离相同时左右边优先。
2. 松手后角色立即完成滑入，收起完成才显示窄小的箭头把手；鼠标停在松手位置不会打断收起。上下把手为横向，左右把手为纵向。
3. 收起后将鼠标移开把手，再重新悬停即可展开；直接点击把手也能立即展开。展开后可以点击、双击或右键操作。鼠标离开角色且没有正在操作的菜单或设置窗口时，约 1 秒后再次完整收回。
4. 把展开的角色拖离边缘，恢复普通桌面状态。靠近另一条边松手可以换边停靠。
5. `Ctrl + Alt + Y` 会解除停靠、关闭点击穿透并召回主屏幕；关闭贴边开关也会恢复完整角色。

停靠期间暂停自动漫游和随机动作。番茄钟继续运行，计时结束的通知仍遵循通知/勿扰设置，但不会展开已收起的角色。

停靠把手置顶且可接收鼠标；展开期间暂时允许交互，即使原先启用了点击穿透也能拖出角色。解除停靠后恢复原来的置顶与点击穿透偏好。

边缘以当前显示器的工作区为准，避开任务栏；动画裁剪在该工作区内，不会滑到相邻显示器上。更改大小或皮肤后会重新计算停靠位置；角色大于工作区时解除停靠。显示器或缩放导致工作区变化时，恢复完整角色并调整到可见区域。

程序记录展开时的位置，不直接恢复贴边收起状态；上次设为隐藏的实例重启后仍隐藏，其余实例完整显示。角色“隐藏”同时隐藏该角色和把手，托盘“隐藏全部”作用于全部实例，之后可从角色管理显示或用快捷键召回。

## 互动与专注计时

在“设置 → 行为”中打开“点击互动”。小幅鼠标移动仍视为点击，超过系统拖动阈值才开始拖动。启用点击穿透时，角色不接收点击或拖动；使用托盘或 `Ctrl + Alt + Y` 召回。

“鼠标靠近时停步”默认开启，距离可调。自动走动会在当前显示器工作区内转向；暂停时保留剩余路程，鼠标离开后继续。自动动作的频率仍由随机待机间隔、走动间隔控制。

从角色右键或系统托盘打开“专注计时”：

工作、学习、阅读都可以使用同一套专注与休息计时。自 v2.9 起，“学习陪伴”“学习记录”统一改名为“专注计时”“专注记录”，已有记录和计时设置原样保留。

1. 在面板中选择“专注”或“休息”，拖动圆环设置分钟数；也可点击中央数字直接输入，或选择常用时长。首次默认专注 25 分钟、休息 5 分钟，以后记住上次设置。
2. 需要中断时点击“暂停”，稍后点击“继续”；重置按钮结束并重置当前计时，不删除已完成记录。
3. 专注完成后，面板显示完成状态，桌面通知提示休息，角色可播放打招呼动作。
4. 点击“开始休息”，默认 5 分钟；也可以用跳过休息按钮回到准备专注。
5. 休息完成后，手动开始下一次专注，不自动累计下一轮。

计时面板支持最小化到任务栏，最小化和关闭面板都不会停止计时，随时可从任务栏或托盘再次打开；完全退出程序会结束当前计时。本次完成次数只统计当前程序运行期间完成的专注。电脑休眠期间按经过的时间计算，唤醒后最多完成当前这一段，不会补出多轮专注。

### 待查看完成提醒（v2.11）

- 专注或休息完成后保留一个待查看标记。数字 `1` 表示有未查看的完成提醒，不是今日次数，也不重复累加。
- 计时面板有任务栏按钮时使用系统叠加角标；同时更新托盘图标作为备用。面板关闭、任务栏隐藏或系统不显示叠加图标时，仍可通过托盘查看。
- 点击任务栏恢复计时面板、通过菜单打开计时面板，或在已经显示的计时面板中进行鼠标/键盘交互，会清除标记。清除不会开始下一段，也不会关闭程序或角色。
- 托盘存在待查看提醒时，单击托盘图标打开计时面板并清除标记；没有提醒时，原有双击切换全部角色显示的行为不变。
- 开始下一段或重置也会清除旧标记。勿扰期间或关闭“桌面通知与完成动作”时不生成新标记，关闭通知会清除已有标记；历史记录不受影响。重启不补发旧提醒。
- 不因完成而自动弹出计时面板，不自动截图。系统通知气泡仍遵循原有设置；截图过程中暂缓本程序气泡，但保留符合条件的待查看状态。

任务栏角标由 Windows 绘制，其位置与外观不保证与其他应用完全相同。部分系统小图标设置可能不显示角标，可使用托盘备用提醒。

“专注与休息动作联动”默认开启：专注运行时，桌面角色和计时面板头像使用 `running` 工作动作；暂停、休息和准备阶段回到 `idle`。专注工作动画优先于随机待机和自动走动，手动互动仍可用，单次互动结束后恢复工作。没有工作动作的皮肤使用待机，不会报错。休息阶段恢复原有自动行为，仍受勿扰设置和皮肤能力限制。

专注或休息完成时，在开启动作联动和“桌面通知与完成动作”、且未处于勿扰的情况下，角色与头像挥手约 3 秒；没有挥手动作时尝试跳跃，再回退待机。桌面角色正在拖动、点击、漫游、操作菜单或设置、播放手动动作时不被打断，完成动作最多等待 10 秒，过期丢弃。隐藏或贴边收起时不强制展开，勿扰期间的动作不补发。面板头像独立播放，最小化时停止绘制但不停止计时。

### 圆环计时面板（v2.3）

- 自 v2.9 起，顶部保留小头像、本次完成次数和勿扰状态，不再常驻显示角色姓名；悬停头像可查看姓名。时间和圆环为主要信息，角色动画联动仍保留。
- 完整与迷你计时面板统一使用 Segoe UI / 微软雅黑 UI 系统字体，数字采用常规字重而非超细字重；不需要单独安装字体，也不改变其他窗口字体。
- 专注可设 1–120 分钟，休息可设 1–60 分钟；两个时长分别保存到原有桌面配置，不新增皮肤参数。
- 圆环支持拖动，经过顶部时保持在最小或最大值，不突然绕回另一端。松手保存；连续键盘或滚轮修改合并保存，关闭面板也会保存已完成的调整。
- 点击数字输入整数，回车或移开焦点保存，Esc 放弃本次数字编辑；不合法的输入会提示，并阻止开始计时。圆环获得焦点后，方向键微调 1 分钟，Page Up / Page Down 调整 5 分钟，Home / End 到达两端。
- 运行中及暂停时锁定圆环、数字和阶段切换，不改变当前剩余时间。需要重设本段时，先点重置；已完成后可直接选择下一阶段并调整，也可按原流程开始休息或专注。
- 保存失败提示并恢复原值；详细角色设置仍打开时，先关闭该窗口再调整，避免两个草稿互相覆盖。
- 圆环在计时中显示剩余比例；减少动态效果时停止圆环过渡，仍正常计时。
- 拖窗口四边或四角可调整大小，支持系统最小化、最大化和还原。默认 400 × 560，常规最小尺寸 320 × 460；系统可用区域更小时保留滚动兜底。
- 拖标题栏、头像区或非交互空白处可移动窗口；圆环、数字输入、按钮和滚动条不会触发拖窗。调整窗口不会重置计时或丢弃正在输入的分钟数。
- 紧凑尺寸隐藏本次完成次数和底部时长摘要，保留角色、计时、预设、操作和专注记录入口；空间充足时自动恢复。圆环保持圆形且限制最大尺寸，文字和按钮不整体等比缩小。
- 开始计时后平滑收起预设区域，窗口本身不突然改变大小；减少动态效果时直接切换布局。
- 正常窗口的位置和大小保存在 `desktop-v2.json` 的 `FocusWindow` 中，拖动结束后合并保存，关闭面板或正常退出时保存最后调整。最大化、最小化不会覆盖正常尺寸，重开面板恢复正常位置和大小。
- 拔掉显示器、改变缩放或屏幕工作区后，窗口会限制到当前显示器可用范围；保存失败显示提示，保留上次有效配置。旧配置不需要手工迁移。

“设置 → 专注与休息”仍可调整专注和休息时长；此入口修改时长不会截断正在运行或暂停的计时，新时长在下一段开始时生效。专注时默认暂停自动走动和随机动作，手动互动仍可用。

### 桌面角色调度（v2.7）

角色动画按实际经过的单调时间播放，不再把定时器回调次数当作帧数。界面繁忙时跳过已过期帧；隐藏或收纳时暂停，恢复后继续剩余的帧时长。单帧循环皮肤不启动帧计时器，原始素材和作者设置的帧时长不变。

仅开启随机动作或自动走动时，程序等待下一次任务期限；开启鼠标注视才保持短周期观察。菜单、拖动、设置及勿扰等状态会停止不适用的自动调度；暂停走动时降低接近检测频率，稳定贴边时不重复更新未变化的视图。这不代表整个程序停止计时，专注计时仍独立运行。

### 迷你悬浮钟（v2.4，v2.9 调整布局）

- 点击计时面板右上角的“迷你模式”图标，收起为小浮窗；点击“展开计时面板”回到完整圆环。只切换布局，不创建第二份计时或重启当前一段。
- 迷你模式顶部同排显示“专注/休息”标题、小头像和准备/进行中/已暂停/已完成状态；下面的倒计时与标题左对齐，采用 34 号常规字重和等宽数字。姓名仅在头像悬停提示中显示。保留开始/暂停/继续和重置；调整分钟数、跳过休息或查看专注记录时展开完整面板。
- 默认 320 × 104，可在 280–480 的宽度、104–200 的高度范围内拖边缩放。拖文字、头像或空白处移动窗口，按钮不会触发拖动。
- 已有保存的迷你窗口尺寸不会因升级被覆盖。如果仍是以前的 128 高度，可以把下边缘向上拖到 104；重新打开后保持调整后的尺寸，位置与置顶设置不变。
- 图钉控制迷你模式是否置顶，默认不置顶；返回完整面板不强制置顶。两种模式分别记忆位置和尺寸，重开时恢复上次模式。
- 迷你模式的关闭按钮只关闭面板，计时继续。完全退出程序仍会结束当前计时。
- 模式、迷你尺寸、屏幕位置和置顶偏好保存在原有 `FocusWindow` 配置中；旧配置默认打开完整面板。保存失败保留原模式并显示提示；减少动态效果时停用切换淡入。

定时休息提醒默认关闭，开启后按设定间隔提示活动、喝水和放松眼睛。番茄钟运行期间不叠加定时提醒；专注或休息结束时重新计算提醒间隔。

勿扰模式会暂停自动走动、随机动作以及通知和完成动作，但不会停止计时或手动互动。定时勿扰使用本机时间和 `HH:mm` 格式，支持例如 `22:00 → 08:00` 的跨午夜范围；开始与结束相同表示全天。勿扰期间到期的通知会丢弃，不会在恢复后补发。

桌面通知通过 Windows 托盘通知发送，不会自动打开计时窗口或抢占输入焦点；显示和声音还受 Windows 通知设置影响。关闭“桌面通知与完成动作”时，计时结果仍会显示在面板中。

## 离线台词气泡（v2.3）

入口为“角色管理 → 设置 → 应用 → 角色台词”，或角色设置的皮肤页中的“台词”按钮。台词窗口展示当前皮肤，点击保存后立即生效，不受外层设置窗口“取消”影响。

- 支持点击（含双击）、拖动结束、专注完成和休息完成四类台词；每行一条，每类最多 8 条，每条最多 80 字符。某类留空表示不显示该类台词。
- “显示台词气泡”和“气泡间隔”是全局设置，默认开启、间隔 30 秒，可调为 5-300 秒。同一时刻最多一个气泡，约 6 秒后消失；冷却中的消息直接略过，不排队补发。
- 不抢焦点、不拦截鼠标、不改变角色窗口尺寸；正在拖动、走动、停靠、隐藏、操作角色菜单或设置的角色不会弹出气泡。角色移动或隐藏时，已有气泡消失。
- 勿扰模式会关闭台词；专注完成台词还遵循“桌面通知与完成动作”设置。多角色共用计时，只选择一个可用角色发言；专注记录不受台词或通知开关影响。
- 台词优先级为：个人台词 → 皮肤内置 `speech` → 通用台词。“恢复默认台词”回到皮肤内置或通用内容，点击保存后去掉个人覆盖。
- 个人台词按皮肤 id 保存在 `desktop-v2.json` 的 `Speech` 中，同皮肤的多个实例共用内容，最多保存 32 个皮肤。个人覆盖不会写进皮肤 ZIP；作者要随皮肤分发台词，可使用 [可选 speech 字段](PET_FORMAT.md#离线台词v230-起)。
- 全部是本地文本，不需要 AI 接口、API key、语音服务或联网。通用台词为应用提供的短句，不代表角色官方台词。

## 专注记录与目标（v2.3）

从计时面板底部的“专注记录”，或“角色管理 → 设置 → 应用 → 专注记录”打开。可查看今日专注分钟数、完成次数、近 7 天统计与完成记录，设置 1-720 分钟的每日目标；小窗口下保留周总量并收起柱图，为记录列表留出空间。

记录规则：

1. 只记录完整完成的专注段，时长取该段实际采用的设定值；暂停时间不累计，休息和手动取消不计入。
2. 一场专注只有一条记录，不随桌面角色数量增加；关闭角色或计时面板不停止共享计时。
3. 跨午夜按完成时的本地日期计入，保存当时的时区偏移，之后更换时区不会移动旧记录的日期。
4. 休眠沿用原计时规则，唤醒后最多完成当前一段，不补出多轮记录。这是计时完成记录，不监控屏幕内容，也不测量实际投入程度。
5. 完全退出程序会结束未完成计时；重启恢复已保存记录和目标，不恢复未完成段。升级前的历史不会凭空补回。

数据独立保存在 `%APPDATA%\YeShunguangPet\study-history.json`，原子写入并保留 `study-history.json.bak`。容量上限为 20000 条、8 MiB，不自动删除旧记录。写入失败时，新记录暂留内存，计时面板和记录窗口会提示，可点击记录窗口的重试按钮；退出前应确认保存成功。

损坏或不支持的记录文件不会自动覆盖。读取失败时，可先备份损坏原件，用有效的 `.bak` 恢复当前文件，再点击重试；程序会按唯一编号合并本次仍在内存中的新增记录。如果先退出程序，未保存的内存记录不会保留。学习历史和个人台词不自动上传，也不包含在诊断导出包中。

## 诊断与日志（v2.15）

入口为“角色管理 → 设置 → 应用 → 诊断与日志”，或角色设置中的“关于 → 诊断与日志”。可以查看运行信息、资源摘要、配置备份状态、预览脱敏后的最近日志、打开当前日志目录，或导出本地 ZIP。

- 默认写入 `%APPDATA%\YeShunguangPet\logs`；失败时依次尝试 `%LOCALAPPDATA%\YeShunguangPet\logs` 和 `%TEMP%\YeShunguangPet\logs`。以诊断窗口显示的实际路径为准。
- 三个位置都不可写时，保留有大小上限的内存记录，诊断窗口明确显示“日志仅保存在内存中”，仍可导出；程序退出后内存记录不再保留。
- 每个日志目录最多保留当前和上一份日志，单个文件约 2 MiB，运行过程中也会滚动。导出只读取有大小上限的最近记录。
- 诊断包只含 `report.json`、`logs.txt` 和 `README.txt`，不收集原始配置、精灵图、屏幕截图、环境变量清单或系统事件日志，也不会自动上传。
- 资源摘要包含托管内存、进程私有内存、精灵图租约、角色数量、贴图数量和截图状态，只用于本地排查，不包含角色身份或屏幕坐标。
- 如果显示存在配置 `.bak`，可以点击“恢复配置备份”。当前配置会保留为 `.pre-recovery.bak`，恢复后需要重启程序；主配置损坏时程序启动也会优先尝试最后一次有效备份。
- 常见个人路径、账号、网址和密钥字段会自动脱敏，当前角色的名称与 ID 不列入运行信息。自由文本不能保证全部识别，分享前可检查预览或 ZIP 内容。

发生致命错误时，程序先停止活动、清理资源，再显示一次带错误编号和实际日志位置的提示；可选择保存脱敏诊断包，然后退出。异常退出不写回可能不完整的运行状态，普通退出仍正常保存设置。后台未观察到的任务异常仍只记录，不一律终止程序。

这项改进增强故障定位能力，不代表此前未复现的崩溃已查明或修复。反馈问题时，请附诊断包、错误编号和报错前最后一次操作；不要先删除原配置或日志。

### 运行活动采样（v2.8）

从“角色管理 → 设置 → 应用 → 诊断与日志”打开“活动采样”页，手动开始后再复现拖动、贴边、菜单或自动动作问题。该入口打开非模态诊断窗口，不会禁止其他角色窗口的操作；若从一个仍打开的模态角色设置窗口进入，请先关闭角色设置再复现桌面操作。

- 默认不采样；开始后每约 500ms 刷新列表，最多持续 5 分钟，可随时停止或清除。最小化时仍在限定时间内采样，但不刷新表格。
- 显示角色状态、当前动作和帧、活动计时器、帧/其他回调数、帧回调超期 P95、上次规则决策及规则编号。状态变化只从开始采样时记录，不回溯此前行为。
- 帧超期基于单调时钟与已调度的帧期限，不是屏幕呈现延迟或 GPU 帧率。每个角色最多保留 128 个延迟样本、128 条状态变化，导出合并后最多 256 条变化。
- 本地列表可显示角色名称，导出仅使用本次采样内的编号，不包含名称、皮肤 ID、源文件路径、鼠标坐标或原始规则。角色移除后编号不复用。
- “导出诊断包”包含当前或已停止的采样快照，仍只生成 `report.json`、`logs.txt` 和 `README.txt`。未开始或已清除时不附带采样内容，不自动上传。
- 停止、超时、关闭窗口或退出桌宠会解除采样订阅。采样和表格刷新本身有额外开销，排查结束后应停止。

### 可配置行为（v2.8）

动作编辑器新增“行为规则”页，可编辑条件、候选动作、权重和冷却。它只影响空闲自动动作，不覆盖用户交互及系统保护。完整字段、示例和调度说明见 [角色行为规则](BEHAVIOR_RULES.md)。

## 用 AI 制作自己的角色

完整教程：[用 AI 制作角色皮肤：步骤与可直接使用的提示词](AI_SKIN_GUIDE.md)。

1. 准备角色的全身参考图、脸部细节和风格要求。
2. 将 [皮肤格式文档](PET_FORMAT.md) 和 [默认 pet.json](../Pets/YeShunguang/pet.json) 一起提供给 AI，使用教程中的提示词。
3. 先确认角色外观，再生成各动作、组装透明精灵图，并查看播放预览。
4. 获取同一文件夹中的 `pet.json` 与 `spritesheet.png`，也可以将这个文件夹打包成单个角色 ZIP。
5. 打开“设置 → 皮肤 → 导入皮肤”，直接选择 ZIP 或新角色的 `pet.json`，预览后点击“保存”。

制作完整皮肤需要图片生成和文件处理能力。桌宠的导入功能负责读取制作完成的皮肤包，单张立绘不会自动变成动画。默认叶瞬光的 JSON 可作为技术模板，其他角色的外观应使用自己的参考图。

开发者可以使用仓库中的 [皮肤 SDK](../skin-sdk/README.md)：模板位于 `skin-sdk/pet.template.json`，校验命令为 `scripts/validate-skin.ps1`。它调用程序本身的皮肤解析器，支持校验目录中的 `pet.json` 和单角色 ZIP。

## 皮肤管理

在“设置 → 皮肤”左侧按缩略图选择角色，右侧预览动作。下方图标按钮悬停可查看名称。

- **导入**：选择单角色 ZIP 或 `pet.json`，验证通过后复制到用户皮肤目录。同 ID 已存在时不会自动覆盖。
- **导出**：导出选中皮肤为 ZIP，只包含原始 JSON 和 PNG，不附带个人设置、日志或其他皮肤。分享前确认素材使用权。
- **更新**：仅对导入皮肤可用，选择相同 ID 的 ZIP 或 `pet.json` 并确认。旧文件保留备份，失败时回退；点击“保存”后桌面采用新版本。
- **删除**：仅对没有任何桌面实例使用的导入皮肤可用，需要确认。先切换或关闭使用它的所有实例，再删除皮肤。随附角色不能在界面中更新或删除。

导入、更新、删除会立即修改皮肤库，设置页的“取消”只取消选择和偏好，不撤销这些操作。更新备份在用户皮肤目录的 `.backup-*` 下，删除的文件保留在 `.deleted-*` 下。v1.5 起可使用“备份与恢复”管理这些文件；备份不参与正常皮肤扫描，程序不会自动清理它们。

## 动作配置编辑器

在“设置 → 皮肤”选中角色，点击铅笔图标“编辑动作配置”。本版从已有的有效皮肤开始编辑，不提供 AI 绘图或单张立绘转动画。

1. 左侧查看原始精灵图，缩放或点击“适应窗口”；网格的行列编号从 0 开始。
2. 右侧选择动作，设置启用状态、所在行、起始列、帧数及每帧时长。点击网格可设置动作起始格，高亮范围对应动作帧。
3. 预览随配置变化，可暂停或重播；单次动作播到末帧停止。待机必须循环，挥手、跳跃和失败动作不能循环。
4. “注视方向”页可启用或关闭注视，并分别选择 16 个方向的格子。当前编辑中关闭再开启会保留参数；关闭状态保存或导出时不包含方向坐标。
5. “保存更新”仅适用于 ID 不变的导入皮肤，确认后保留旧版备份；“另存为皮肤”写入用户目录，ID 冲突时自动分配 `-copy` 后缀。随附角色默认使用新 ID，不能原地覆盖。
6. 返回设置，预览确认后点击“保存”应用到桌面。导出 ZIP 只写出草稿配置和原始 PNG，不改变皮肤库。

格宽、格高、行列数必须与原始 PNG 总尺寸匹配；编辑器不裁剪、缩放或重绘 PNG 文件。配置越界、时长或 ID 不合法时不能保存、导出，但会保留上一份可用预览。关闭编辑器会询问是否放弃未保存的修改，“重置配置”恢复最近载入的源文件配置。

### 撤销、时间轴与批量时长（v2.6）

- 左下角的撤销/重做按钮用于恢复编辑步骤，也支持 `Ctrl+Z`、`Ctrl+Y` 和 `Ctrl+Shift+Z`。同一个输入框中连续输入会合并为一步；切换输入框、动作或执行撤销后会开始新步骤。
- 切换动作、缩放精灵图、播放及定位帧不会产生编辑历史。撤销后继续修改会丢弃重做分支；历史最多保留 100 个检查点，并受 4 MiB 内存预算约束，不把 PNG 放进每个检查点。
- 预览下方的上一帧/下一帧按钮和时间轴会暂停播放，并定位到对应帧。时间轴按每一帧的实际时长分布，不把所有帧当成等长。重新播放非循环动作时，到末尾后可从第一帧开始。
- 帧列表下方可输入 20-10000 ms，选择“全部帧”或“所选帧”，点击应用图标。列表支持 `Ctrl`/`Shift` 多选；一次批量调整只需一步撤销。
- 无效输入也可以撤销；只有校验通过才允许保存、导出和继续播放。撤销只作用于内存草稿，不撤销已经保存到皮肤库的文件操作，旧文件仍通过“备份与恢复”找回。

### 源文件安全刷新（v2.6）

1. 打开“编辑动作配置”，点击右上角文件夹图标找到当前源文件位置。导入会复制皮肤，因此原始下载目录与当前编辑的目录可能不同；建议将随附角色另存为自己的皮肤副本后再修改。
2. “自动刷新源文件”默认在本次编辑器窗口中开启。用外部文本编辑器修改该目录的 `pet.json`，或替换其引用的 PNG；不需要重新打开窗口。刷新按钮可单次检查，即使关闭自动刷新，也不会强制重新开启该开关。
3. 后台等待文件事件稳定，连续读取两份一致的完整快照，并执行原有 PNG、尺寸、动作、路径及 ID 验证。校验失败时保留当前预览，修复文件后再自动或手动检查。
4. 如果当前草稿有未保存修改，不会被外部文件替换。选择“载入外部版本”才放弃当前草稿；选择“保留草稿”后可另存或导出，不能直接覆盖外部版本。
5. 载入外部版本后清空旧编辑历史，避免旧参数配到新图片。关闭编辑器停止监听，迟到结果不会继续修改窗口。

自动刷新只更新**当前编辑器预览**，不会修改任何源文件，也不会自动替换正在桌面上运行的角色。保存皮肤库更新后，仍需回到角色设置点击“保存”应用到桌面。皮肤 ID 改名需要另存副本，不能靠原地改 ID 热替换。

文件监视可能受到磁盘、编辑器保存方式或系统事件延迟影响；连续快照检查不能证明多个外部写入属于同一个事务。批量替换文件时建议先关自动刷新，替换完毕后手动检查。每个 PNG 仍受既有文件大小与尺寸限制。

## 备份与恢复

在“设置 → 皮肤”点击“备份与恢复”图标。可以按历史版本/已删除筛选，查看名称、目录时间、占用大小和预览。目录时间来自文件系统，不代表精确的操作发生时间。

- **恢复皮肤**：缺少此 ID 时重新导入；已有用户皮肤时，确认替换并先备份当前目录，损坏的同 ID 用户目录也可恢复。随附皮肤不可覆盖。
- **恢复为副本**：创建独立皮肤，不替换已有角色；适合与随附角色 ID 冲突的备份。
- **导出 ZIP**：把选中备份单独导出。恢复和导出均保留原备份，可再次使用。
- **永久清理**：只清理选中的那份备份，确认后不可撤销，不影响皮肤库中的副本。损坏清单可显示并清理；包含符号链接、目录联接或无法安全检查的目录禁止操作。

恢复与清理立即生效，不能用设置页的“取消”撤销；恢复后的桌面角色仍需回到设置点击“保存”。本版不批量删除备份，也不会自动清理。

## 常见问题

### 无法拖动

从托盘“角色管理”打开对应角色的设置，检查“点击穿透”；也可按 `Ctrl + Alt + Y` 召回全部角色并关闭穿透。

### 找不到角色

按 `Ctrl + Alt + Y`，或在托盘菜单中选择“召回全部”。召回同时关闭点击穿透。程序启动、拖动结束和可见角色的显示器工作区变化时，也会约束窗口位置。

### 快捷键没有反应

打开“设置 → 常规”检查召回快捷键状态。若注册失败，通常表示 `Ctrl + Alt + Y` 已被其他程序占用；托盘菜单中的“召回全部”仍然可用。

### 程序异常退出

在“设置 → 关于”中打开日志目录，将最新的 `app.log` 与复现步骤一起提交到 Issues。日志只保存在本机，不会自动上传；提交前请检查并移除不希望公开的本机路径。

### 开机启动后找不到程序

开机启动记录包含 EXE 的完整路径。移动程序前先关闭“开机启动”，移动完成并重新运行后再开启。

### 如何卸载

1. 在任意角色的设置中关闭“开机启动”；没有角色时可先添加一个。
2. 从托盘菜单完全退出。
3. 删除解压后的程序目录。
4. 如需清除偏好设置，再删除 `%APPDATA%\YeShunguangPet`。

## 精灵图约定

皮肤结构和动作参数由 `pet.json` 定义。默认叶瞬光位于 `Pets/YeShunguang/`，沿用 8 列 x 11 行、每格 `192 x 208` 的原始精灵图：

| 行 | 状态 | 使用列 |
| --- | --- | --- |
| 0 | 待机 | 0-5 |
| 1 | 向右拖动 | 0-7 |
| 2 | 向左拖动 | 0-7 |
| 3 | 打招呼 | 0-3 |
| 4 | 跳一下 | 0-4 |
| 5 | 失败 | 0-7 |
| 6 | 等待确认 | 0-5 |
| 7 | 工作中 | 0-5 |
| 8 | 检查成果 | 0-5 |
| 9 | 看向方向 000 到 157.5 | 0-7 |
| 10 | 看向方向 180 到 337.5 | 0-7 |

其他皮肤可以采用不同的行列、单元格尺寸、帧数和播放时长。在“设置 → 皮肤 → 导入皮肤”中选择新皮肤的 ZIP 或 `pet.json`，预览后保存即可切换。导入的文件保存在 `%APPDATA%\YeShunguangPet\Pets`，升级程序不会覆盖。

格式、最小示例和动作说明见 [皮肤包格式](PET_FORMAT.md)。仅有单张普通 PNG 不足以导入，还需描述帧位置的清单。

## 开发与构建

安装 .NET 8 SDK 后，在仓库根目录执行：

```powershell
.\scripts\publish-self-contained.ps1
```

开发机没有 .NET SDK 时，可以使用无管理员权限的引导脚本：

```powershell
.\scripts\bootstrap-dotnet-and-publish.ps1
```

生成便携版 ZIP 和 SHA256 文件：

```powershell
.\scripts\package-release.ps1
```

成品位于 `artifacts`。推送与项目版本匹配的标签（例如 `v2.0.0`）后，GitHub Actions 会验证皮肤、互动和陪伴逻辑，再自动构建并创建对应 Release。

多角色架构、性能结果、测量边界和待人工验收项目见 [v2 性能与验收报告](V2_PERFORMANCE.md)。探针源码在 `benchmarks`，不包含在便携包的 EXE 中。

本地运行皮肤测试：

```powershell
dotnet run --project tests/PetTests.csproj --configuration Release -- .
```

发布脚本会先验证原始精灵图 SHA256。只要精灵图发生任何字节变化，构建就会停止。
